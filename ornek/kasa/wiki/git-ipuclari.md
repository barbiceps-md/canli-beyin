# Git İpuçları

- `git switch -c yeni-dal` — yeni dal aç.
- `git log --oneline --graph` — geçmişi kısaca gör.
- `git restore dosya` — yerel değişikliği geri al (dikkat: geri gelmez).
- Gizli bilgi asla depoya girmez; `.gitignore` ilk iş.
